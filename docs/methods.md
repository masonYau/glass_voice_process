# 方法说明与示例结果

本文只描述算法和统计数字，不包含任何录音内容。示例数据：某款智能眼镜的 7 段实采录音（单声道 16 kHz，各 5 分钟），
底噪约 -55 ~ -80 dBFS，佩戴者语音峰值 -10 ~ -20 dBFS，对话者只比底噪高 5~15 dB，语音占比 2%~80%，有较多敲击/碰撞瞬态。

## 1. 公共流程（v3 / v4）

```
读入（16 kHz 单声道）
 → 噪声样本 = WebRTC 判为非语音 ∩ 电平较低一半 → 平稳谱门限降噪（denoise）
 → 语音检测：v3 = 双路 Silero + 滞回（vad_dual）；v4 = pyannote segmentation-3.0（PyannoteSegmenter）
 → 瞬态剔除①：VAD 段内浊音帧比例 < 0.25 的段丢弃（voicing_track + refine_mask）
 → 佩戴者 / 他人：1.2 s 窗口的电平 + 直混比，GMM 二分（split_wearer）
 → 对话者聚类：CAM++ 嵌入，片段级平均链接 AHC + 质心合并（cluster_neural）
 → 瞬态剔除②：说话人段再查一次谐波（drop_unvoiced）
 → 段内按电平切分换人（split_turns；v4 需 pyannote 换人点佐证）
 → 增益：分段增益 + 2 s 慢速 AGC、缺口桥接、慢释放 / 提前起音、底噪约束、瞬态上限（apply_gains）
 → 放大区 5 ms 块尖峰压制（suppress_clicks）→ 限幅 -1 dBFS（limiter）
```

### 关键设计与原因

| 环节 | 问题 | 做法 |
|---|---|---|
| 瞬态剔除 | 敲击/摩擦被当成对话者放大 30 dB | 带通 60~1000 Hz 自相关周期性；背景约 0.01，语音 0.4~0.8；比例 < 0.25 丢弃 |
| 尖峰压制 | < 10 ms 的咔哒被放大成尖峰（峰值 0.9） | 帧级上限（目标 +8 dB）+ 5 ms 块峰值超过 ±100 ms 中位数 4 倍且 > -14 dBFS 时压回；峰值降到约 0.6 |
| 对话者人数 | MFCC 会把同一人按距离（电平）拆成 2~5 人 | CAM++ 嵌入 + 两步聚类；合成测试中"同一人近/远"正确合并为 1 人 |
| 放大上限 | 只比底噪高几 dB 的对话者放大后底噪大 | 放大上限 = min(35, -45 dBFS − 降噪后底噪) |
| 断音 | VAD 漏检的弱语音处增益从 +35 dB 掉到 0 dB | 两侧都放大、≤ 2.5 s 的缺口桥接；放大段后每 0.4 s 最多降 30 dB；下一段前 0.1 s 提前到位 |
| 弱尾音漏检 | 降噪把弱尾音再压低约 11 dB，Silero 判为非语音 | 双路检测（加 Codex 式"原始高通 + 快速 AGC"一路）+ 滞回；v4 改用 pyannote |
| 段内换人 | 1.5 s 的短段里佩戴者说完对话者接话，整段判给佩戴者 | 段内按电平切分；v4 用 pyannote 逐帧换人点佐证（否则会把佩戴者句中停顿误切） |

## 2. v5（Codex 方法）

```
原始录音 → 90 Hz 高通 + 50 ms 快速 AGC + tanh（检测用副本）
 → sherpa-onnx：pyannote segmentation-3.0 分段 + CAM++ 声纹 + FastClustering（阈值 0.7）；最短发言 0.18 s / 静音 0.2 s
 → 每人一轨：单人区间从原声取出；两人重叠区间 MossFormer2 分离并按声纹分配
 → 每轨固定增益（第 70 百分位电平 → -23 dBFS，-18 ~ +26 dB），混音 = 原声 + Σ 轨 ×（增益 − 1）
 → 混音与分轨共享 -1.5 dBFS 峰值限幅
```

特点：不降噪、段外保持原音量、能分离两人重叠；漏检的弱语音不会被放大，也不会被"切断"成 0 dB 以下（保持原音量）。

## 3. 示例结果（7 段实采）

佩戴者 − 对话者有效电平差（较响 40% 帧），处理前 → 处理后：

| 版本 | 电平差范围 | 说明 |
|---|---|---|
| 原始 | 23 ~ 39 dB | |
| v3 | 1.8 ~ 4.5 dB | |
| v4 | 1.6 ~ 3.9 dB | |
| v5 | 3.0 ~ 21 dB | 漏检的部分保持原音量；佩戴者只衰减到约 -12 ~ -17 dBFS |

断音（≤ 5 s、两侧都放大、原始仍有声音的增益缺口 / 50 ms 内增益下降 ≥ 15 dB 的陡降），7 段合计：

| 版本 | 缺口 | 陡降 |
|---|---|---|
| 未做桥接/慢释放时 | 30 | 69 |
| v3 | 11 | 2 |
| v4 | 9 | 5 |
| v5（增益为估算） | 46 | 98 |

以 v5 的对话者分段为参照，"v5 标为对话者而我们未标注"的区间：v3 为 73 个 56 s，v4 为 15 个 23 s（该指标对同样使用 pyannote 的 v4 有利）。

合成测试（公开语音样本合成，佩戴者近讲 + 对话者远处混响 + 噪声，有真值）：

| 测试 | v3 / v4 佩戴者判别 | 对话者纯度 / 覆盖度 |
|---|---|---|
| 2 个对话者 | 100% | 100% / 100% |
| 中文：同一对话者近/远（电平差 9.5 dB） | 100% | 100% / 100%（MFCC 时会拆成 3 人） |
| 中文：A 近/远 + B | 100% | 100% / 100% |

## 4. 说话人嵌入的选择

| 嵌入 | 中文同人 / 异人余弦相似度 | 英文 | 实采低信噪比 |
|---|---|---|---|
| CAM++（默认） | 0.69 / ≈ 0 | 异人最高 0.67，区分差 | 簇内 0.40~0.58，稳定 |
| ECAPA | 0.52 / ≈ 0 | 同人 0.70 / 异人 0.11，区分好 | 簇内 0.11~0.38，不稳定，容易拆成很多人 |
| MFCC | — | — | 按电平/距离拆分同一人 |
